Matriz MVP: dashboard (low-fidelity wireframe)

Draft, 2026-11-05. Grayscale structure only, no branding or final styling. Element IDs E-xx and assumptions (UI-Ax) are explained in docs/ui/README.md.

The dashboard combines three existing MVP views: "My tasks" (FR-14), the project list with progress (FR-08, FR-18) and in-app notifications (FR-17). It adds no summary, chart or statistic of its own (F41 Manager overview is out of scope).

Example data is fictional. "Today" in the examples is 2026-11-05.

Section states: loading and error (assumption UI-A4)

No edge case covers these. Each section loads on its own, so one failing section does not hide the others.

Loading E-19

Grey placeholder rows plus the text "Loading…" for screen readers.

Error E-20

This section could not be loaded.
Try again

Saved work is never lost by a display error (NFR-03).

Overdue marking: "! Overdue" text label with a heavier border, never colour alone (FR-19, NFR-06). A box reading "hidden for this user type" marks an element that this user type does not see; dashed boxes elsewhere are empty or open-menu areas. Every element is reachable with the keyboard in the order shown, top to bottom and left to right (NFR-06).
